# 🎬 IMDb Movies Data Analysis
This project involves analyzing IMDb movie datasets using SQL to extract valuable insights regarding movie ratings, genres, and trends, and presenting the findings in a structured visual report

## 🛠️ Tools & Technologies Used
* **Query Language**: SQL (MySQL / PostgreSQL)
* **Reporting Tool**: PDF Presentation / Data Visualization
* `**Abirami IMDb project.sql**: Contains all the SQL queries written for data analysis
* **PRSQL-01 IMDB Movies Presentation CLEANED.pdf** : Visual presentation highlighting the key findings and insights
## 📊 Key Insights
* Extracted top-performing movies based on ratings and votes using aggregate functions.
* Analyzed genre-wise distribution and trends using complex SQL queries.
